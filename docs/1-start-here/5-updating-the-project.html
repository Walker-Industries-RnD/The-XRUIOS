5 - Updating The Project

Creating a new update for the XRUIOS is a generally simple process!

You can start by going to the XRUIOS.Barebones repo and adding a new library.

From there, add the class as a style of worker as an entry and rebuild the project.
Now, add the method in the Capabilities.cs file.

Finally, create a new issue under the format of "New Capability" below!
