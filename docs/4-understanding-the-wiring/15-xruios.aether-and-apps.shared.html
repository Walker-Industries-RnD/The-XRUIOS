15 - XRUIOS.Aether and Apps.Shared

What is it?

Two libraries sit on the app side of the broker. XRUIOS.Apps.Shared is what the desktop apps use. XRUIOS.Aether is what a Godot or Aether Engine project uses. Both open the same encrypted connection to the Manager that 3 - A CMD App opens by hand; they only package it.

XRUIOS.Apps.Shared

A net10.0 library that every UI app under src/apps references. It references XRUIOS.SecureLayer and XRUIOS.Interfaces.

WorkerBroker

The one connection an app opens to the Manager. WorkerBroker.ConnectAsync(appName) finds credentials in this order and uses the first that works:

  1. Environment: XRUIOS_APP_ID, XRUIOS_APP_PSK and XRUIOS_BROKER_ADDR. The Manager sets these when it starts the app.
  2. Dev creds file: %LocalAppData%\XRUIOS\Public\<appName>.creds. This exists only while the Manager runs with --dev-creds.
  3. Enrollment: ask the running Manager over its control pipe. The Manager checks the caller is the registered executable in its approved folder.

The address, the password and the id are never written into the app. An app cannot choose where to connect or invent a password: a copy of the executable on another machine, or running from a different folder, gets nothing. InvokeAsync<T>(capability, args) makes a call, and Subscribe(onEvent) opens the event stream on its own session.

AppShell

A static holder. AppShell.InitializeAsync("XRUIOS.App.Time") connects once at page load, and from then on any page can use AppShell.Broker.

Holes

A hole is a small static class under Holes/ that wraps one or two capabilities in a clean method, so a XAML page calls one line. For example TimeSource.ClockAsync() calls Now and parses the reply, and CalendarPicker.ListAsync() calls ListCalendars. The holes are: AppLaunchTarget, CalendarPicker, ClipboardHistory, EventFeed, KeyboardLayoutPicker, MediaAlbumPicker, NotificationFeed, PocketPalIntent, PowerControl, ThemePicker, TimeSource, VolumeMixer, WeatherFeed and WorldEventsFeed.

A hole can only call what its app was granted. If a hole calls a capability that is missing from the app's entry in AppCatalog, the broker refuses it. When you add a hole, add its capabilities to the app's grant list in the same change.

EventFeed

Live updates instead of polling. EventFeed.OnThemeChanged(handler) and the other On... methods return a stream; keep it as long as the page wants updates and dispose it afterwards. Callbacks arrive on a background thread.

AssistantProvider

Runs your assistant for the whole XRUIOS. Give it an IAssistantInterpreter and it answers every question asked through PocketPal. See the example in 8 - Building a XRUIOS App.

WidgetChrome and SceneCycler

WidgetChrome is the draggable borderless window content for the small apps (widgets). SceneCycler is a temporary development helper: an app registers named scenes, and a corner button cycles through them. It is meant to be deleted once an app has real navigation.

XRUIOS.Aether

A net8.0 library, because Godot .NET projects target net8.0 while the rest of the XRUIOS targets net10.0. Instead of referencing the net10 build, it compiles the client half of the secure layer from the same source files (EclipseSecureClient, PqcGate, XruiosEvents, XruiosEventStream, XruiosEnrollment, AppProvisioning) and references XRUIOS.Interpreter.

AetherShell

The engine-side half of the Aether backend. The engine connects to the Manager as a normal app, receives the events it was granted, and hands each one to the interpreters it registered.

  • ConnectAsync(appName, post, onError) finds credentials from the environment, or enrolls. The engine's executable must be registered with the Manager like any other app.
  • InvokeAsync<T>(capability, args) calls any capability the engine was granted.
  • Godot's scene tree can only be touched from the main thread, so every callback goes through post. In a Node, that is a => Callable.From(a).CallDeferred().
  • ShellNotify, ShellAppearance and ShellLaunch events go to the engine's INotificationInterpreter, IAppearanceInterpreter and IShellAppInterpreter. Events no registered interpreter handled are raised on the Unhandled event.

See 13 - XRUIOS.Interpreter for the interpreters and 8 - Building a XRUIOS App for a full example.
