7 - XRUIOS.Core

What is it?

The XRUIOS Barebones Context Shim is the runtime environment provider that connects XRUIOS workers to their execution context. It serves as the bridge between the Manager's orchestration and the worker's operational environment.

While seemingly simple, this is the most important file, quite literally acting as what everything else builds on.

Architecture

Core Principle

To begin, the XRUIOS.Core is what manages giving each worker the data path, the public path and each worker it's own encryption key.

The Manager is the sole authority for context provision:

The Manager passes context to workers through environment variables. These variables are passed from the Manager process to the worker process at launch, never touching disk.

Environment Variable Purpose
XRUIOS_DATA_PATH Account focused directory
XRUIOS_PUBLIC_PATH Public data directory
XRUIOS_WORKER_KEY Base64-encoded worker-specific encryption key

Security Model

Key Hierarchy

┌─────────────────────────────────────────────────────────────┐
│                     Master Key                              │
│              (held by Manager in memory)                    │
│                         │                                   │
│          ┌──────────────┼──────────────┐                   │
│          │              │              │                   │
│          ▼              ▼              ▼                   │
│     Calendar Key    Alarm Key    Processes Key            │
│     (worker 1)     (worker 2)    (worker 3)              │
└─────────────────────────────────────────────────────────────┘
Property Implementation
Worker isolation Each worker receives a key derived from the master using HKDF-SHA256
Cross-worker protection Worker A cannot read Worker B's encrypted data
Zero-trust handoff Keys are passed via environment variables, never stored
Memory safety SecureData buffers are zeroed when disposed

Fallback Mode (Development)

When running outside the Manager (e.g., during development), the shim falls back to:

Property Fallback Value
DataPath ./XRUIOS (current directory)
PublicDataPath ./XRUIOSPublic (current directory)
encryptionKey "Test" (hardcoded, development only)

Warning: The fallback key ("Test") is insecure and must never be used in production. It exists solely to allow workers to run standalone during development.**
